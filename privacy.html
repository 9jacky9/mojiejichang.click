隐私政策 (Privacy Policy)

魔戒机场坚决捍卫用户隐私权，公开透明阐释我们的数据处理规范与无日志运作机制。

1. 核心承诺：绝对零活动日志记录（Strict Zero-Logs Policy）

我们郑重承诺：魔戒机场绝不记录、绝不存储、亦绝不分析任何用户的在线活动日志。

具体而言，在您接入并使用我们的专线网络期间，我们绝对不会保留以下任何数据：

  • 不记录用户的浏览足迹：绝不记录您访问的任何具体网址、域名、网络路径或下载内容。
  • 不记录真实原始IP与出口对应：绝不记录您建立连接时分配的外部 IP 地址或客户端本地公网 IP 对应关系。
  • 不保留DNS查询记录：所有 DNS 请求均通过私有加密递归服务器在内存中瞬时完成解析并立即丢弃，不在磁盘上写入日志文件。
  • 不留存连接时间戳与会话详情：绝不关联记录特定用户的准确登录时间、登出时间或传输数据包特征。

2. 纯内存化（RAM-Only）运行架构

魔戒机场核心骨干中继服务器采用定制化无盘引导及纯内存镜像（RAM-Only OS）技术。所有操作系统进程与数据转发流水均在易失性内存中执行，服务器一旦断电或热重启，内存中的全部临时缓存将彻底、不可逆地归零抹除，从物理架构层面根除了数据泄露的风险。

3. 最小化账户数据管理

为了保障账单核验与套餐额度重置，我们仅收集维持账户正常运转所不可或缺的最简必要信息：

  • 注册凭证：仅需要一个供您登录控制台与重置密码的电子邮箱地址（支持匿名邮箱）。
  • 流量配额计数：仅统计当前计费周期内已消耗的总数据量（如已用 45GB / 320GB），用于执行限额策略，该计数绝不包含任何通信内容或流量来源。

4. 传输加密技术标准

用户客户端与节点之间建立的每一次网络握手，均采用业内前沿的高强度加密协议（TLS 1.3、ChaCha20-Poly1305 或 AES-256-GCM）。即便传输路径穿透公共 Wi-Fi 或第三方 ISP，任何外部窃听者也仅能识别随机混淆密文，无法窥探或解密真实数据负载。

5. 第三方披露与法律协作

由于我们从一开始就践行零日志记录架构，因此在物理和技术层面上，我们没有任何历史数据或用户活动记录可供披露、调取或转售给任何第三方商业机构或数据分析机构。
